# cuursor

Маленькая программа для Windows, которая делает переход курсора между мониторами
разного размера и разрешения плавным. Написана на Rust, живёт в трее, весит ~0.5 МБ.

## Проблема

Windows склеивает мониторы по **пикселям**, а не по сантиметрам. Например, слева
24" Full HD (1920×1080, ~92 PPI), справа 27" 2K (2560×1440, ~109 PPI):

* у 2K-монитора край на 360 px выше, чем у Full HD, поэтому в части края курсор
  **упирается** и не переходит;
* там, где переходит, он **прыгает**: пиксель 1000 на 27" находится на высоте
  ~233 мм, а пиксель 1000 на 24" — на ~277 мм, курсор оказывается на 4–5 см
  выше или ниже, чем «должен».

## Как это решается

cuursor ставит низкоуровневый хук мыши (`WH_MOUSE_LL`) на отдельном потоке с
высоким приоритетом. Пока курсор внутри монитора, хук делает одно сравнение и
пропускает событие. Когда курсор пересекает край, хук переводит позицию в
миллиметры (размер панели берётся из EDID монитора), находит ту же физическую
точку на соседнем мониторе и ставит курсор туда. Участки края, напротив которых
физически ничего нет, «прилипают» к ближайшей точке соседа, так что курсор
никогда не застревает.

Режимы (`%APPDATA%\cuursor\config.toml`):

* `physical` (по умолчанию) — курсор переходит в ту же физическую точку.
  Выравнивание (`align`) по умолчанию `auto`: берётся из того, как мониторы
  расставлены в «Параметры → Система → Дисплей» (ближайшее из
  «верхние края / центры / нижние края на одной линии»). Можно задать явно:
  `top`, `center`, `bottom`.
* `proportional` — весь край одного монитора растягивается на весь край
  другого (верх в верх, низ в низ).

Если размер монитора определился неверно (см. «Мониторы…» в меню трея),
его можно задать вручную, например:

```toml
[[monitor]]
match = "1920x1080"
diagonal_in = 24
```

Не трогаются: синтетический ввод (RDP, планшеты), случаи, когда игра или
программа ограничила курсор (`ClipCursor`), и «телепорты» больше `max_jump_px`.

## Установка

1. Скачайте `cuursor.exe` из [Actions](../../actions) (артефакт
   `cuursor-windows-x64`) или из Releases.
2. Запустите. Значок появится в трее: двойной клик — вкл/выкл, правый клик —
   меню (мониторы, настройки, автозапуск, выход).
3. В меню включите «Запускать при входе в Windows».

Совет: в «Параметрах дисплея» поставьте мониторы так, как они стоят на столе
(например, выровняйте по нижнему краю, если низ экранов на одной высоте).

## Сборка из исходников

```powershell
winget install Rustlang.Rustup     # или https://rustup.rs
rustup default stable
cargo build --release              # -> target\release\cuursor.exe
cargo test                         # тесты геометрии
```

Нужен MSVC Build Tools (rustup предложит установить). Кросс-сборка из Linux:
`rustup target add x86_64-pc-windows-gnu`, пакет `mingw-w64`, затем
`cargo build --release --target x86_64-pc-windows-gnu`.

## Похожие проекты

* [LittleBigMouse](https://github.com/mgth/LittleBigMouse) — тот же подход
  (физическая раскладка по EDID), C#/C++, с редактором раскладки.
* [MouseUnSnag](https://github.com/MouseUnSnag/MouseUnSnag) — убирает только
  «залипание» на краях, без пересчёта по физическому размеру.

## Устройство кода

* `src/layout.rs` — геометрия: какие края соприкасаются и куда переходит курсор
  (без зависимостей от Windows, покрыто тестами).
* `src/edid.rs` — разбор EDID (физический размер и модель).
* `src/config.rs` — настройки.
* `src/win/` — хук мыши, перечисление мониторов, трей, автозапуск.
